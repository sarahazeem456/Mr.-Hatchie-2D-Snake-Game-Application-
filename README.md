# Mr.-Hatchie-2D-Snake-Game-Application-
A colourful, feature-packed 2D Java Swing Snake game featuring custom snake skins, timed bonus foods, and wandering crab hazards.

# Mr. Hatchie:
Mr. Hatchie is a classic retro Snake game built in Java using Swing and AWT graphics. Guide your snake across a checkerboard grid, feast on delicious treats, unlock unique visual styles, and dodge deadly hazards!

Features
Customization: Name your snake and pick from multiple skins (Classic, Fire, Forest, and dynamic Rainbow).
Appetizing Treats: Munch on standard food for steady growth, or race against the clock to grab limited-time 
Blue Bonus Food(+3 points & triple length!).
Crab Hazards: Watch your step—wandering crabs spawn periodically and will end your run on contact.
Quality of Life: Spacebar pause support, real-time score tracking, and persistent session high scores.
Full-Screen Canvas: Runs borderless and maximized right out of the box.

Controls
Arrow Keys (`↑`, `↓`, `←`, `→`): Steer Mr. Hatchie
Spacebar: Pause / Resume game
Mouse:Select skins and restart from the menu
